# MoodTube 광고(수익화) 초보 가이드

> 목표: 앱에 광고를 넣어 수익을 만들되, 음악 감상 경험을 해치지 않게.
> 현재 MoodTube는 **Google AdMob 연동이 완료**되어 있고, 홈 "스마트 픽" 리스트 안에 광고 슬롯이 들어가 있습니다.
> 출시 전 남은 핵심은 **Play Console Data Safety에 광고/광고 ID 사용을 정확히 반영**하는 것입니다.

---

## 1. 어디에 광고를 넣을까 (MoodTube 추천 배치)

지금 화면 구조 기준으로, 거슬리지 않으면서 노출이 잘 되는 자리:

| 우선순위 | 위치 | 광고 형태 | 비고 |
|---|---|---|---|
| ★★★ | 홈 "스마트 픽" 리스트 **3번째 항목 자리**에 1개 | **네이티브(Native)** | 카드 디자인과 똑같이 맞춰서 자연스럽게. 가장 추천. |
| ★★★ | 검색 결과(ResultsScreen) 리스트 **중간(예: 4번째)** | 네이티브 또는 배너 | 사용자가 스크롤하며 자연스레 봄. |
| ★★ | 보관함(Library) 화면 **맨 아래 고정 배너** | **배너(Banner)** | 빈 공간 활용. |
| ★ | 앱을 **다시 열 때** 가끔 | **앱 오픈(App Open) 광고** | 콜드 스타트 시 1회. 너무 자주는 금지. |
| △ | 플레이어 **진입 직전** 가끔(3~4회당 1회) | 전면(Interstitial) | 재생 직전이라 거슬릴 수 있음 → 신중히, 빈도 제한 필수. |

**절대 넣지 말 곳(정책 위반/오클릭 위험):**
- 무드 다이얼·재생 버튼·미니플레이어 컨트롤 **위/바로 옆**
- 하단 내비게이션 버튼 위
- 화면을 가려 실수로 누르게 만드는 위치

> MoodTube에 잘 맞는 1순위는 **"스마트 픽 리스트 안 네이티브 광고 1개"** 입니다.
> 가장 덜 거슬리고, 우리 카드 디자인과 똑같이 만들 수 있어요.

---

## 2. 어떤 광고 형태인가 (쉽게)

- **배너(Banner)**: 화면 위/아래에 붙는 작은 띠 광고. 가장 쉬움.
- **네이티브(Native)**: 우리 앱 카드처럼 생긴 광고. 디자인을 우리가 맞춤 → 가장 자연스러움.
- **전면(Interstitial)**: 화면 전체를 덮는 광고(닫기 버튼 있음). 수익 높지만 자주 쓰면 사용자 이탈.
- **앱 오픈(App Open)**: 앱을 켤 때 잠깐 뜨는 광고.
- **보상형(Rewarded)**: "광고 보면 보상" — 게임용. MoodTube엔 보통 불필요.

## 3. 가입할 곳과 순서 (초보자 단계별)

### A. AdMob 계정 만들기
1. <https://admob.google.com> 접속 → 본인 **구글 계정**으로 가입.
2. 결제(수익 받을 계좌/주소) 정보 입력. (수익 일정 금액 넘으면 지급)
3. 좌측 **앱(Apps) → 앱 추가 → Android → "아직 스토어에 없음"** 선택(출시 전이면).
   - 출시 후에는 Play 스토어의 MoodTube와 **연결**해 주세요.
4. 생성된 **앱 ID** 기록: `ca-app-pub-XXXXXXXX~YYYYYYYY` 형태.

### B. 광고 단위(Ad Unit) 만들기
1. 그 앱 안에서 **광고 단위 추가** → 형태 선택(예: 네이티브 / 배너 / 전면).
2. 각 광고 단위 ID 기록: `ca-app-pub-XXXX/ZZZZ` 형태.
3. 처음에는 **테스트 광고 ID**로 개발하고(실수 클릭 = 계정 정지 위험), 출시 직전에 실제 ID로 교체.
   - 테스트 배너: `ca-app-pub-3940256099942544/6300978111`
   - 테스트 전면: `ca-app-pub-3940256099942544/1033173712`
   - 테스트 네이티브: `ca-app-pub-3940256099942544/2247696110`

### C. 앱에 연결할 부가 항목
- **app-ads.txt**: 개발자 홈페이지(러바블로 만든 사이트) 루트에 `app-ads.txt` 파일을 올려 두면 수익 보호에 좋음. AdMob이 내용(한 줄)을 알려줍니다.
- **동의(UMP) SDK**: 유럽(GDPR) 등 사용자 동의 팝업. AdMob 가이드대로 설정.

## 4. 현재 코드(Flutter) 세팅

2026-06-13 기준 MoodTube에 반영된 상태:

1. `pubspec.yaml`에 `google_mobile_ads` 추가 완료.
2. `android/app/src/main/AndroidManifest.xml`의 `<application>` 안에 **AdMob 앱 ID** 메타데이터 추가 완료:
   ```xml
   <meta-data
       android:name="com.google.android.gms.ads.APPLICATION_ID"
       android:value="ca-app-pub-9993388177095923~4694181215"/>
   ```
3. 앱 시작 시 광고 초기화 호출 완료. 초기화 실패가 앱 실행을 막지 않도록 예외 흡수 처리.
4. `lib/ads/` 조건부 임포트 구성 완료: 모바일은 실제 광고 구현, 웹은 stub이라 웹 빌드/미리보기 안전.
5. 홈 "스마트 픽" 3번째 카드 뒤 광고 슬롯 삽입 완료.
6. `minSdkVersion`은 `google_mobile_ads` 요구치(23+)를 만족합니다.

## ⚠️ 5. 광고를 넣으면 꼭 같이 해야 하는 것 (중요)

MoodTube는 AdMob을 사용하므로 광고 식별자(Advertising ID) 등이 처리될 수 있습니다.

1. **개인정보처리방침 갱신 완료**: `PRIVACY.md` / `docs/privacy.html`에 Google AdMob 및 광고 식별자 처리 안내 반영.
2. **개인정보처리방침 공개 URL**: `https://legitstudio.cc/moodtube/privacy`
3. **Play Console → Data Safety 양식 갱신 필요**: 데이터 수집/공유 항목을 광고에 맞게 체크.
4. **가족 정책**: 만 13세 미만 대상 아님(이미 명시) 유지.
5. 본인·지인이 **자기 광고 클릭 금지**(계정 영구 정지 사유).

## 6. 추천 진행 순서 (현실적인 로드맵)

1. 실기기 QA에서 광고 로딩 실패가 나도 앱이 멈추지 않는지 확인.
2. Play Console Data Safety에 AdMob/AD_ID 사용 반영.
3. Play Console 인증 완료 후 AAB 업로드 및 심사 제출.
4. 출시 후 데이터 보고 전면/앱오픈 광고를 "빈도 제한" 두고 조심히 추가.
